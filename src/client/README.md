# Cliente de help by Ine

Ver [README del proyecto](../../README.md) para funciones, permisos y compilaciones.

- `npm ci`: instalar dependencias.
- `npm start`: abrir el servidor en http://localhost:4200.
- `npm test`: pruebas en Chrome aislado, sin datos reales.
- `npm run check:style`: verificar formato.
- `npm run mobile:sync`: compilar y sincronizar Android/iOS.
